# 🍽️ - onmangeou

A simple app to vote for a place to eat

## 🚀 - Quick start

```sh
# Clone the repo
git clone git@github.com:LalbaAnthony/onmangeou.git

# Move into the project directory
cd onmangeou

# Copy .env.example file to .env and fill in the required environment variables.
cp .env.example .env

# Start the development server
npm i ; npm run dev
```
